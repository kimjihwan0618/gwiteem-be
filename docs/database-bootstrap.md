# 초기화된 DB 복구 및 샘플 데이터

저장소 루트에서 `.env`의 `DATABASE_URL`을 사용한다. 현재 모델은 선택 서비스의
8개 테이블이며, 최신 Alembic revision은 `87af8eca06fd`이다.

```powershell
python -m scripts.bootstrap_database
python -m scripts.bootstrap_database --apply
```

기본 실행은 스키마 상태만 확인한다. `--apply`는 빈 스키마에 모델의 테이블,
인덱스, 외래키, 제약조건을 생성하고 모델과 비교한 뒤 Alembic head를 기록한다.
이후 샘플 데이터를 같은 트랜잭션에서 생성·갱신한다. 오류가 발생하면 롤백한다.
기존 테이블을 삭제하거나 초기화하지 않는다. 기존 DB는 이미 head이고 모델과
일치할 때만 샘플 데이터 갱신을 허용한다. 다른 revision이면 기존 마이그레이션을
검토하고 `python -m alembic upgrade head`를 먼저 실행해야 한다.

최초 마이그레이션 `a395b8e042c1`은 레거시 테이블에 대한 ALTER부터 시작하므로
완전히 빈 DB에서는 `alembic upgrade head`만으로 복구할 수 없다. 이 스크립트는
이 경우에만 현재 모델로 직접 생성한다. 기존 이력이나 모델 필드는 변경하지 않는다.

기존 DB의 샘플 활동만 갱신하려면 다음 명령을 사용한다.

```powershell
python -m scripts.refresh_sample_data
python -m scripts.refresh_sample_data --apply
```

첫 명령은 변경을 계산한 뒤 롤백한다. `--apply`는 적용 전 모든 모델 테이블의
행을 `.database-backups/activity-before-*.json`에 백업하고 트랜잭션으로 저장한다.
이 폴더는 Git에서 제외된다. 백업에는 사용자 정보가 있으므로 외부에 공유하지 않는다.

생성 계정은 `김민준`, `이서연`, `박지훈` 등 세 글자 이름을 사용한다.
질문은 기존 카탈로그의 33개를 유지한다. 다른 사용자가 추가한 질문을 자동 삭제하지
않으며, 전체 질문 수가 30~35개 범위를 벗어나면 적용을 중단한다.

생성 데이터 구성:

| 테이블 | 건수 |
| --- | ---: |
| users | 20 |
| choice_questions | 33 |
| choice_reasons | 132 |
| choice_votes | 질문별 생성 계정 5~20명 참여 |
| choice_likes | 질문별 0~19개 |
| choice_comments | 질문별 0~16개, 보호할 댓글이 있으면 유지 |
| choice_replies | 댓글별 0~4개 추가, 기존 작성 답글은 유지 |
| choice_comment_likes | 댓글별 서로 다른 참여 인원 |

질문은 기존 마이그레이션의 카테고리별 카탈로그를 재사용한다. 사용자 이메일은
`demo01@example.test`부터 `demo20@example.test`까지 예약 도메인을 사용하며,
비밀번호는 설정하지 않아 로그인 계정으로 사용할 수 없다. 이메일 전송은 하지 않는다.
기존 생성 템플릿 댓글·답글과 생성 계정의 투표·좋아요만 갱신한다. 식별되지 않는
직접 작성 댓글·답글은 작성 계정과 관계없이 보존한다. 보존할 답글이나 다른 사용자의
댓글 좋아요가 있으면 부모 댓글 ID와 작성 시각도 유지한다. 사용자 추가 활동은
위 생성량에 포함되지 않으므로 실제 건수는 달라질 수 있다.

`--seed`로 분포를 재현하거나 다른 분포로 바꿀 수 있다. 반복 실행 시 생성 데이터는
교체되므로 누적되지 않지만 행 ID와 시각은 바뀔 수 있다. 질문 게시 시각, 활동 시각,
투표 선택지와 댓글에 언급된 선택지를 맞춘다. 로그인 가능한 기존 계정의 인증정보는
변경하지 않는다.

로컬 인메모리 SQLite에서 테이블 생성과 모델 비교, 두 번 실행 시 건수 동일,
직접 작성 데이터 보존, 외래키 무결성, 투표의 이유가 같은 질문에 속하는지 검증한다.
접속 시간 초과 시 DB 서비스와
방화벽, 포트포워딩, VPN 접근 경로를 확인한다. 접속정보는 출력하지 않는다.
